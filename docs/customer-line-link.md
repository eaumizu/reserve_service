# 予約ごとのLINE連携

0013_customer_line_links.sqlを新しいSupabaseクエリで実行します。既存の予約を更新・削除しません。
管理画面の店舗LINE設定に表示されるWebhook URLを、対象Messaging APIチャネルのWebhook URLに登録します。「検証」成功後に「Webhookの利用」を有効にします。予約連携コードへの一律自動返信を避けるには公式アカウントの応答メッセージ設定を確認してください。

お客様は予約専用リンクを開き「連携コードを発行」を選択し、表示された全文を本人のLINEから店舗の公式アカウントに10分以内に送ります。「連携結果を確認」で連携済み表示を確認します。公式アカウントへの友だち追加だけでは予約は紐づきません。

コードは128ビット乱数でDBにはSHA256のみ保存されます。再発行で古いコードは無効になり、使用済み・期限切れ・予約リンクが再発行されたコードは利用できません。署名検証済みの個人トークのみ受け付け、グループは対象外です。予約ごとの紐づけで、他の予約へ自動適用しません。Web予約操作は従来どおりLINE不要です。

今回は紐づけとWebでの確認までです。LINEへの予約通知、連携の解除・変更、Webhook処理の監視は後続で追加します。連携済みの相手へ上書きする操作はありません。Webhookに予約の内容や専用リンクを返信しません。
