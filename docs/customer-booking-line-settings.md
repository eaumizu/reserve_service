# お客様の予約操作と店舗別LINE設定

## 今回の範囲
- Web予約の完了画面から専用リンクを開いて、予約確認・日時変更・キャンセルができる。LINE登録は不要。
- メニュー・担当者は維持し、15分刻みの空き枠から日時変更。確定時にDBが再検証。
- 変更・キャンセルは施術開始前の確定予約のみ。変更先には既存の受付期限を適用。
- スタッフは予約詳細から専用リンクを発行・再発行できる。再発行で古いリンクは失効。
- 管理者は店舗設定で公式アカウント名、友だち追加URL、チャネルID、秘密情報を設定できる。
- LINE自動通知、LINEアカウントとの予約紐づけ、LINE上での操作、メール自動送信は未実装。公式アカウントの接続確認後に実装する。

## 適用
0010の後に0011_customer_booking_access.sql、0012_store_line_settings.sqlを順に適用する。
LINE秘密情報を保存する場合、VercelにLINE_SETTINGS_ENCRYPTION_KEY（暗号学的乱数で生成した32バイト、64桁の16進数）をサーバー専用環境変数として登録する。NEXT_PUBLIC_は付けない。変更すると既存の暗号文を復号できなくなるため、キーは継続して管理する。
公式アカウント名・URLだけの登録には暗号化キーは不要。

## 取り扱い
専用リンクは256ビットのランダム値。DBにはSHA-256ハッシュのみ保存。URLフラグメントから読み込み、APIにはPOST本文で送る。画面はnoindex/no-referrer、APIはprivate/no-store。ログや分析にリンク・API本文を記録しない。
専用リンクの期限は発行後400日または予約終了後30日のうち遅い方。画面のリンク保有を予約操作の権限として扱う。予約番号・電話番号のみでリンクを再取得できる公開APIは作らない。
予約確認には必要な項目のみ返し、電話・メール・スタッフ用メモを返さない。
LINE秘密情報はAES-256-GCMで暗号化し、店舗IDを追加認証データに使用。管理APIは保存済みフラグのみ返し、秘密情報や暗号文は返さない。チャネルID変更時は旧チャネルの秘密情報を消す。
