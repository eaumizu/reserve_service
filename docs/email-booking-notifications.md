# 予約完了・変更・キャンセルのメール通知

## 設定
1. Supabase SQL Editorで `supabase/migrations/0019_email_booking_notifications.sql` 全文を新しいクエリに貼り付け、Runを押します。0018まで適用済みであることが前提です。
2. Vercel Productionの `RESEND_API_KEY`、`LINE_SETTINGS_ENCRYPTION_KEY`（既存LINE設定と共通の暗号鍵）、予約サイトの公開URLが設定済みであることを確認します。暗号鍵を変更すると既存の暗号化リンクは復号できません。
3. 管理画面「前日連絡 → 店舗のメール通知設定」で店舗の送信元が認証済みなら、新しいドメイン登録は不要です。

## 確認
LINE未連携で自分のメールアドレスを入力して新規予約すると、日本時間の予約日時と本人専用の確認・変更・キャンセルリンクをメール送信します。そのリンクで日時・担当者の変更、キャンセルを行い、それぞれ通知を確認してください。
新規Web予約時にはまだLINEと紐付いていないため、最初はメールです。その後LINE連携した予約の変更・キャンセルはLINEを優先します。メールアドレスもLINE連携もない予約は電話で連絡します。

前日通知の有効・無効とは独立した、予約操作に伴う通知です。予約・通知対象の保存は同じDBトランザクションで行い、送信失敗で予約操作を取り消しません。未認証店舗ではメール通知対象を作成しません。適用前の予約の変更メールには、以前保存した予約リンクを利用する案内が表示される場合があります。

## 未送信
「店舗のメール通知設定」に直近20件の通知と未送信件数を表示します。「未送信の予約メールを再送」で送信できます。失敗後の再試行は2分後からです。同一通知IDでResendの重複防止を利用します。23時間を過ぎた未送信は自動再送対象から外し、店舗で連絡を確認してください。「配信受付済み」はResendの受付を表し、受信箱への到達はResendのEmails画面や受信側で確認します。

送信元設定・メールアドレス・LINE連携・本人専用リンクが変更された古い通知は再送しません。本人専用リンクの元トークンは店舗に紐付けて暗号化し、通常の管理画面や通知一覧には表示しません。リンク再発行で旧リンク用の暗号化データも削除します。
