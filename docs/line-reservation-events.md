# 予約変更・キャンセルのLINE通知

0015_line_reservation_events.sqlを新しいSupabaseクエリで適用します。既にLINE連携している予約も対象です。お客様の予約専用ページと管理画面のどちらで操作しても、DBトリガーが同じトランザクションで変更・キャンセル通知を登録します。未連携予約、スタッフメモの更新、施術完了・無断キャンセルでは通知を作りません。

変更には変更前・変更後の日本時間の日時、メニュー、担当者を、キャンセルには対象日時・メニュー・担当者を表示します。予約専用リンクは以前保存したものを引き続き使えます。リンク再発行やLINE連携の再設定は不要です。電話番号・スタッフメモは通知に含めません。

予約操作の成功後に通知を送信します。LINE送信が失敗しても予約操作の成功は保持し、未送信の案内を表示します。管理者は「店舗設定 → 未送信LINE通知を再送」で最大2件ずつ再送できます。送信が成功しても記録更新が失敗した場合は、同じ固定リトライキーで受理済み409を処理し、重複を防ぎます。23時間を超えた通知は自動的に期限超過扱いとなり、再送しません。期限超過の件数も再送結果に表示します。

今回の変更・キャンセル通知には定期バックグラウンド再送はありません。未送信が残る場合は配信上限・認証情報を確認し、管理画面から再送してください。期限を過ぎた場合は別の連絡手段を使用します。LINE APIの受理が実際の配信を保証するものではなく、ブロック等では届かない場合があります。

新しいテスト予約をLINE連携し、専用リンクから変更・キャンセルして通知を確認します。別のテスト予約で管理画面からも同じ操作を確認します。すでに連携済みの予約でも利用できます。
