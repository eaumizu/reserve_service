# Googleカレンダーの予定で予約枠を閉じる

## 初回設定
1. 0025まで適用済みのSupabase SQL Editorで `0026_google_calendar_busy.sql` の全文を実行します。
2. 最新の管理画面 https://reserve-service.water7daily.workers.dev/admin を開きます。
3. 店舗設定 → LINE・メール・前日通知の設定 → Googleカレンダー連携で「Googleの予定で予約枠を閉じる」を有効にします。
4. 接続済みの「店舗予約」カレンダーに「予定あり」の予定を作り、お客様用予約画面で該当日を選びます。全担当者の該当枠が出ないことを確認します。
5. Googleの予定を移動・削除し、予約画面が自動更新されて枠が戻ることを確認します。

既存のOAuth権限（calendar.events）を使うので通常は再接続不要です。別の個人用カレンダーを読み込む機能ではありません。店舗共通カレンダー上の予定は全担当者の受付を止めます。担当者個別の予定による停止は別の機能です。

## 反映するタイミング
数分おきの定期同期ではなく、空き枠を取得するたびと、新規予約・日時／担当者変更の確定直前にGoogleへ確認します。お客様用の新規予約画面は、表示中は30秒ごと、別タブから戻ったときにも空き枠を自動取得します。手動更新ボタンはありません。取得中も入力内容と、まだ空いている選択枠を保ちます。確認画面で選択枠が埋まった場合は、入力を保って選び直しへ戻します。非表示中と予約完了後は自動取得を止めます。古い空き枠からの確定も、Googleの再確認とDBの重複チェックで拒否します。

予約システムからGoogleへ登録した予定は、イベントID・店舗・予約IDに加え、現在の確定予約の開始・終了時刻が一致する場合だけ除外します。Google側で日時・長さを変更した予定や、DBに対応する確定予約がない予定は受付停止として扱います。Google側の編集で予約DBの日時は変わりません。通常の予約同士の重複は従来どおり予約DBで判定します。

## 管理画面での動作確認
Googleカレンダー連携の「受付停止の動作確認」を開き、Google予定の確認日を選んで「Googleの受付停止を確認」を押します。接続先カレンダーの、その日に受付を止める時間帯と確認日時を日本時間で表示します。予定の作成・削除や通知の送信は行いません。Googleから取得できない場合は、0件と表示せずエラーにします。

0件の場合は、予定を登録したカレンダーが接続先と同じか、Googleの予定が「予定あり」か、日付とタイムゾーンが合っているかを確認します。別の個人用カレンダー（例：「water 7」）や「空き時間」の予定は停止対象外です。Googleで受付停止の予定を編集し、登録先を接続中の「店舗予約」に変更してください。予定の色だけでは登録先を判定できません。この動作確認で受付停止を取得した後、お客様用画面で30秒以内の自動更新、またはタブを戻した際の更新で表示を確認します。

通常の予定追加・移動・削除、終日・繰り返し予定、Google側で移動した予約由来の予定、選択後にGoogle予定が追加された場合の予約確定を、テスト用の予定・予約で確認してください。今回のアプリ更新に追加のSQLは不要です（0026適用済みが前提）。

「予定あり」の時間指定、終日、繰り返し予定が対象です。「空き時間」（透明）の予定や削除済み予定は対象外です。終日予定の終了日は含めません。カレンダーのタイムゾーンで解釈し、日本時間の予約枠と照合します。施術の準備・片付け時間も含めて重複を判定します。

## 接続できない場合
この設定が有効な間、Googleの予定を取得できない場合は空き枠の提示・新規予約・日時変更を止めます。既存予約の確認・キャンセル・施術完了などは継続できます。Google OAuthのテスト公開の有効期限にも注意してください。接続を回復するか、この設定を明示的に無効にするとGoogleによる停止を解除できます。

## 実装と制約
予定名・説明・参加者は保存せず、店舗・日付・接続版と時間帯だけを非公開テーブルに保存します。すべてのページを取得してから更新し、ページ取得失敗や上限超過を空き時間として扱いません。同時取得の古い結果や再接続前の結果は破棄します。DBトリガーで90秒を超えた／未完了の確認結果を拒否します。SQLを直接使った新規予約も、この設定が有効なら新しい確認結果が必要です。

Googleと予約DBは別システムのため、Googleへの予定追加と予約確定が全く同時に行われた場合の排他制御はできません。すでに確定した予約とGoogle予定が重なっても、既存予約を自動キャンセルしません。Googleで予約システム由来の予定を編集しても、予約データ自体は変更されません。
