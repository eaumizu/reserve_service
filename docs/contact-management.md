# 連絡管理

0020_contact_management.sqlをSupabase SQL Editorで全文実行してください。0019まで適用済みであることが前提です。

管理画面の「前日連絡」は「連絡管理」に置き換わります。最初に表示するのは未送信・電話対応が必要な通知です。「再送」または「電話で連絡済みにする」で対応します。不在・留守番電話だけでは連絡済みにしないでください。履歴は「通知履歴を見る」を開いたときだけ表示します。詳細を開くとメニュー・担当者・電話番号を確認できます。

メール・LINE設定と前日通知の有効・停止は「店舗設定 → LINE・メール・前日通知の設定」にあります。前日通知の送信は対象全体を処理する既存の方式です。予約変更・キャンセルの再送は同じ予約の未送信通知を処理します。LINE連携完了時の初回通知で再送できないものは電話対応として表示します。再送は管理者、電話対応記録はログイン済みスタッフが操作できます。

電話対応済みの予約通知は送信待ちから外し、履歴に残します。送信済みは配信サービスの受付を意味し、既読を保証しません。対応優先の予約通知は200件、前日連絡は今日・明日の対象を200件まで表示します。古い通知の電話対応記録は、現在の予約内容や変更内容を確認してから操作してください。
