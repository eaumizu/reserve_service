# 顧客台帳と予約時の氏名

0022_reservation_customer_names.sqlをSupabase SQL Editorで全文実行してください。既存の予約には現在の顧客名を引き継ぎます。すでに上書きされた元の名前を推測して復元することはありません。必要な既存予約の訂正は予約時のメールなどの記録を確認して行います。

修正後は各予約に入力時点の氏名を保存します。予約一覧・名前検索・本人専用ページ・連絡管理の表示に使います。同じ電話番号の予約履歴は同じ顧客IDにまとまりますが、後から違う氏名で予約しても台帳の名前や以前の予約時の名前を自動で上書きしません。電話番号の一致は同一人物と断定するものではありません。

例：同じ電話番号で13日に「山田花子」、14日に「山田太郎」と予約した場合、各予約にはそれぞれの入力氏名が表示されます。台帳の名前は最初の氏名を維持します。台帳の訂正・分離・統合の画面は今後の顧客管理機能で扱います。
