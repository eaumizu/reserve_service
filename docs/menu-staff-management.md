# メニュー・担当者の削除と名前なし受付

0021_archive_menu_staff.sqlをSupabase SQL Editorで全文実行します。0020まで適用済みであることが前提です。

店舗設定の各メニュー・担当者に削除ボタンを追加しました。削除後は設定一覧と新規予約候補から外れます。過去の予約・施術結果は保持します。今後の確定予約や片付け時間中の予約で使う対象は削除できません。予約を変更・キャンセルするか施術結果を記録してから操作してください。

メニューが一つならWeb予約で自動選択します。担当者を一人も登録していない場合も一人分の受付枠で予約できます。内部の受付枠は担当者設定の一覧に出しません。担当者がいない状態では、有効なメニューを自動で受付枠に紐付けます。名前は予約画面・メール・LINE通知に出しません。

最初の担当者を追加すると内部の受付枠を引き継ぎます。担当者名は任意で、空欄なら担当者名の表示を省略します。担当者を明示登録した場合は対応メニューを選んでください。登録済み担当者を全員「停止」にした場合は受付停止として扱い、名前なし受付へ勝手に切り替えません。最後の担当者を削除した場合は名前なしの一人分の受付に戻ります。

一人分の受付なので、メニューが違っても同時間帯に重複予約できません。メニューを全部削除した場合は予約できるメニューがなくなるため、少なくとも一つ有効なメニューを残してください。
