# 顧客台帳

0025_customer_ledger.sqlをSupabase SQL Editorで全文実行します。0024まで適用済みであることが前提です。Google未接続でも台帳は使えます。

管理画面の「顧客台帳」で氏名・電話番号を検索し、「顧客の詳細」で予約時の氏名・予約日時・メニュー・担当者・施術結果を確認します。来店回数は施術完了を記録した予約の件数です。予約一覧に顧客用の項目を増やさず、台帳の氏名や店舗用メモは詳細の折りたたみから編集します。

同じ電話番号と氏名で予約すると同じ顧客IDへ紐付けます。全角・半角、氏名の空白、電話番号の区切り文字をそろえて照合します。電話番号が同じでも氏名が違う場合は別の顧客として登録します。メール・LINEの連携だけで施術を受ける本人だと断定しません。同姓同名かつ同じ番号など、入力情報だけでは区別できない場合は店舗で確認が必要です。

台帳名の訂正は管理者、メモの編集はログイン済みスタッフが操作できます。訂正前の氏名でも同じ電話番号から再来予約を照合できます。訂正後の氏名が同じ番号の別プロフィールと衝突する場合、自動統合せず保存を止めます。予約時の氏名は台帳名を訂正しても変わりません。

既存の顧客プロフィールや予約の所属は自動で分離・統合しません。既存台帳に複数の予約名がある場合は、詳細画面で確認を促します。表記揺れを正規化した結果、既存プロフィールが重複する場合も履歴を勝手に移しません。既存顧客の分離・統合と電話番号変更の専用操作は次段階です。

複数のスタッフが同時に編集した場合は、古い画面からの保存を止めます。「顧客台帳を再読み込み」で最新の内容を確認してください。台帳は店舗ごとに分離し、公開の予約ページから検索・取得することはできません。
